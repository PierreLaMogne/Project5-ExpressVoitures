This is my version of the Express Voitures web app for Project5 of Openclassrooms "back-end .NET app developer" studies.

This web app is using .NET 10.0. It could be launched by cloning the project on Visual Studio.

In order to access this web app, you have to configurate your local server in the appsettings.json.
Once done, you need to initialise the database using the package manager console by entering "update-database" in it.
Then, you finaly can launch the Express Voitures web app.

Upon launch, an administrator account will be automatically created.
You will be able to log in with this information:

Email = admin@expressvoitures.com
Password = Admin@123
